# AST vs Parse Tree

## Parse tree

Representa la sintaxis completa del lenguaje. Suele ser más grande y conserva más detalles del código fuente.

## AST

Es una versión más abstracta. Elimina ruido sintáctico y conserva solo lo necesario para trabajar con la lógica del programa.

## Diferencia práctica

- Parse tree: útil para mostrar cómo se reconoce una cadena de texto.
- AST: útil para compilar, analizar y reescribir código.

## Regla simple

Si te importa la forma exacta del texto, piensa en parse tree. Si te importa lo que el código significa, piensa en AST.
