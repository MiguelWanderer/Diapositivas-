# Wiki de Windows Server 2025

Estes es un conjunto de diapositivas con la mision de explicar paso a paso como se puede crear una un servidor de Windows server

## Qué cubre

La documentación está dividida en nodos para que cada tema pueda leerse con calma y poder procesar la informacion segmento a segmento

## Segmentos principales

El laboratorio se organiza en seis módulos principales:

## Instalación y Preparación (A): 
Configuración inicial del servidor.

## Active Directory (B):
Instalación y administración de AD.

## Cliente de Dominio (C): 
Integración de equipos al dominio.

## Servicios de Red (D): 
DHCP, DNS y otros servicios esenciales.

## Políticas de Grupo (E): 
Implementación de GPOs para control centralizado.

## Configuración Avanzada (F): 
Optimización y seguridad del entorno.

Los requisitos previos incluyen conocimientos básicos de sistemas operativos, acceso a una herramienta de virtualización como VirtualBox, la ISO de Windows Server 2025, al menos 50 GB de espacio disponible y conexión a internet.
