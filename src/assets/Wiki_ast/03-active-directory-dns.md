# Active Directory + DNS

## Propósito

Describir la creación y administración de dominios, usuarios y equipos junto con la configuración de DNS.

## Qué resuelve

Permite una correcta resolución de nombres y una administración centralizada de la red.

## Puntos clave

- Crear y organizar el dominio.
- Administrar usuarios y equipos.
- Configurar DNS correctamente.
- Asegurar que los nombres internos se resuelvan sin errores.

## Resultado esperado

Un dominio operativo con identidad, control y resolución de nombres consistentes.
