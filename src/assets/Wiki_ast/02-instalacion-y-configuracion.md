# Instalación y Preparación (Paso A)

Este módulo recoge los pasos principales para preparar el laboratorio de forma ordenada y reproducible.

## Resumen de Pasos

1. **Descargar elementos necesarios**  
   - ISO de Windows Server 2025  
   - VirtualBox u otra máquina virtual compatible  

2. **Verificar descarga de ISO**  
   - Confirmar integridad y checksum válido  

3. **Configurar sistema operativo**  
   - Crear usuario con contraseña segura  
   - Usar ISO en español (experiencia de escritorio)  

4. **Configurar recursos de la VM**  
   - Disco: mínimo 50 GB  
   - RAM: mínimo 4 GB  
   - Procesador: 2 cores  

5. **Configurar red privada**  
   - Crear red llamada **REDLAB**  

6. **Instalación y reinicio**  
   - Esperar instalación completa y reiniciar servidor  

7. **Configurar nombre del servidor**  
   - Asignar nombre: **SRV-DC01**  

8. **Configurar IP fija**  
   - IP: 192.168.10.10  
   - Máscara: 255.255.255.0  
   - DNS preferido: 127.0.0.1  

9. **Verificar Firewall**  
   - Confirmar que esté activo y correctamente configurado  

---

✅ **Fin del Punto A**: Instalación base completada exitosamente.
