# Instalación y configuración

## Propósito

Explicar paso a paso el proceso de instalación de Windows Server 2025 y su configuración inicial.

## Qué se busca lograr

Garantizar un entorno estable, seguro y listo para continuar con la administración del dominio.

## Puntos de trabajo

- Preparar el medio de instalación.
- Instalar el sistema operativo.
- Configurar red y nombre del servidor.
- Aplicar ajustes básicos de seguridad.
- Dejar el equipo listo para los siguientes roles.

## Resultado esperado

Un servidor funcional y ordenado como base para el resto de la infraestructura.
